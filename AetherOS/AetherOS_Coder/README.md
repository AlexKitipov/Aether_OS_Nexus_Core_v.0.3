# AetherOS Coder Workspace

This directory contains user-space coder modules for AetherOS.

## Scope
- Work here for `ADI`, `APM`, and `ARX` updates.
- Keep kernel changes in `AetherOS/kernel` separate unless explicitly requested.

## Modules
- `ADI`: analysis, policy, and sandbox pipelines.
- `APM`: package manifest, install, update, and registry logic.
- `ARX`: runtime context, process, loader, and API surfaces.
